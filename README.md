# Big database with ML  #
This is my Bigdata base Project Repo.
Author - Prakash Gautam

This project focuses on processing and analyzing large-scale LiDAR (Light Detection and Ranging) data using Dask for distributed computing. A local Dask cluster with multiple workers is used to perform data processing efficiently. The project uses LiDAR data from the German state of Thuringia, which is provided in 1 km × 1 km tiles. The data is processed and analyzed using Python and Dask to demonstrate how parallel computing can improve the handling of large datasets.

It consists of four different projects that consisting LiDAR point cloud processing with Dask, Weather station data scraping from the DWD API, and Transfer learning with Keras/Xception on a tree-species image datasets.
